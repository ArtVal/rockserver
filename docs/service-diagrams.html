3. Внутренняя схема RockServer

CURRENT

Axum API

Public GET /health/live, DB-aware GET /health/ready, anonymous /api/v1/search and /api/v1/voice/*; legacy /api/v1/* search/voice routes retain the Bearer boundary. Device-facing GET /api/v1/device-control/catalog/stations|search require the native device-session Bearer, return DeviceStationDto pages without stream_url, and apply per-device rate buckets.

CURRENT

Device-control directory projection

Owner-scoped DeviceControlDirectory через существующие REST GET /api/v1/device-control/directory и WSS directory.snapshot/directory.upsert. Записи содержат опциональный runtime_state — ревизионный DeviceStateSnapshot из персистентной latest-проекции, видимый только caller-ам со скоупом entity.state.read; target без опубликованного state оставляет поле отсутствующим (не null и не сфабрикованным). Без новых endpoints и polling.

CURRENT

Personal-data sync

Account-owned POST /api/v1/sync (native device-session Bearer): один атомарный push+pull запрос. Записи сливаются last-writer-wins по updated_at, курсор server_revision — per-device, tombstones доносят удаления устройствам, офлайн в момент удаления. Лимиты зеркалируют локальный контракт RM-007-A (500/500 живых записей, батч ≤300, история 90 дней, metadata ≤4 KiB, тело ≤256 KiB); retention-sweep раз в час на процесс, purge личных строк удалённых аккаунтов через 30 дней. station_id — opaque, неразрешённые ссылки сохраняются.

CURRENT

API access gate

The deployment Bearer credential protects only legacy /api/v1/* compatibility routes. Account/device pairing uses passkey, browser cookie, CSRF, and a durable device secret that issues short-lived native sessions; no credential is logged. A paired browser account can link Yandex Smart Home through one-time OAuth with the read-only iot:view scope; the server encrypts the token at rest and returns only retrievable temperature readings.

CURRENT

tracing / config

JSON tracing, HTTP и import config, run/page/count logs, graceful shutdown.

CURRENT

DTO / validation

Transport DTO, request_id и contract-compliant ошибки.

CURRENT

Нормализованный запрос и стабильное repository-neutral ранжирование.

CURRENT

QueryParser / LlmProvider

EmbeddingProvider trait

CURRENT

StationRepository

Запущенный сервис использует PostgreSQL + migrations/seed; in-memory repository ограничен deterministic tests.

CURRENT

CatalogImporter

Ограниченный Radio Browser client + import store; отдельный CLI, не request path и не HTTP startup.

CURRENT

Mobile catalog exporter

Отдельный PostgreSQL→SQLite CLI. Выпускает только полный active/playable каталог после строгой проверки; health, embeddings и import runs не экспортирует.

CURRENT

RM-011-G6 cleanup operator

Preview-first one-shot CLI: показывает только безопасные IDs, статусы, counts и причины; apply требует один UUID и точную фразу, отзывает зависимости транзакционно и сохраняет audit/tombstone.

CURRENT

Administrator SPA

Caddy serves the existing first-party Preact/Vite `/admin` route and proxies `/api/v1/admin/*` first. Separate persisted administrator identity has Argon2id login and short-lived revocable Bearer sessions; the SPA keeps that Bearer only in current-page memory. Read-only Devices, Audit and Stations pages return safe paginated projections. RockCast product routes remain public; user identity uses pairing.

CURRENT

Station-icon import

Администратор запускает одну durable background job из `/admin`; источник иконки — явный URL каталога либо favicon, найденный на homepage станции; UI показывает сохранённый прогресс, server-hosted WebP thumbnails и ручную replace/remove override. Нет CLI, cron, startup- или deploy-side импорта.

FUTURE

StreamHealthChecker

Фоновая проверка потоков, не в request path.

4. Данные каталога

CURRENT: versioned migrations создают stations, station_streams, source identity, import_runs, provenance-aware station_embeddings и isolated administrator request records with 30-day retention. Pgvector column не закреплён за dev dimension; exact search сравнивает только одинаковые model/version/dimension. Radio Browser ownership не изменён. Отдельный CLI экспортирует только active/playable станции с единственным primary HTTP(S) stream в проверяемый SQLite-пакет для RockMobile; health/probes, embeddings и import runs туда не попадают. RockCast product routes remain public and pairing is its user-identity boundary.

RockCast / RockMobile

Работают без сервера с baseline; Mobile сначала использует проверенный extended SQLite.

CURRENT: Anonymous /api/v1/voice/* routes are rate-limited; legacy /api/v1/voice/* routes retain a Bearer boundary. The WebSocket GET /api/v1/voice/stream adds bounded PCM16 mono chunks, partial/final transcript events, provider-neutral STT sessions, and final SearchService resolution. RockCast supplies its configured legacy token only for that compatibility boundary and chooses buffered_v1 (default, recognition after commit) or streaming_v3 (SpeechKit chunks during recording) in the start event. The process reports speech_provider_unavailable until a provider key is configured.

КодЗначение контрактаТело
200Успешный ранжированный ответ.SearchResponse
401Bearer credential отсутствует, повреждён или неверен.ErrorResponse + WWW-Authenticate: Bearer
400Тело отсутствует, не JSON или JSON синтаксически повреждён.ErrorResponse
422JSON синтаксически корректен, но нарушает схему или семантическую валидацию.ErrorResponse
429Превышен лимит запросов.ErrorResponse
500Неожиданная серверная ошибка.ErrorResponse

ErrorResponse всегда содержит code, message, request_id и details. Search реализует 200, 400, 401, 422 и 500; 429 остаётся FUTURE. Readiness отдельно возвращает 503 + {"status":"not_ready"} при потере PostgreSQL.
